# QuillMesh Markdown 速查

## 标题与段落

```markdown
# 一级标题
## 二级标题
普通段落
```

## 强调

```markdown
**加粗**  *斜体*  ~~删除线~~  ==高亮==  `行内代码`
```

## 链接与图片

```markdown
[链接文字](https://example.com)
![替代文字](assets/image.png)
```

点击图片可打开大图预览，在预览中使用滚轮缩放。

## 列表与任务

```markdown
- 无序列表
1. 有序列表
- [ ] 未完成任务
- [x] 已完成任务
```

## 引用、代码与分割线

````markdown
> 引用文本

```ts
const editor = 'QuillMesh'
```

---
````

## 表格

```markdown
| 功能 | 说明 |
| --- | --- |
| 外部同步 | 检测 Agent 修改 |
| 冲突保护 | 保留本地未保存内容 |
```

## 公式

```markdown
行内：$E = mc^2$

块公式：
$$
E = mc^2
$$
```

## 高频操作

- `Ctrl+Shift+P`：命令面板。
- `/`：快捷插入。
- `Ctrl+/`：源码模式。
- `Ctrl+Shift+E`：插入或编辑公式。
