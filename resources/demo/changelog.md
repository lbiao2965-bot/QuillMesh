# QuillMesh 功能演示

欢迎使用 **QuillMesh / 织墨**。这份演示文档介绍常用交互，你可以自由编辑。

## 编辑

- [ ] 打开大纲并跳转到标题
- [ ] 按 `Ctrl+Shift+P` 打开命令面板
- [ ] 在空段落输入 `/` 打开插入菜单
- [ ] 选中文字后打开右键菜单

## 外部工具协作

用 Codex、Claude Code 或任意脚本修改当前 `.md` 文件。如果 QuillMesh 中没有未保存内容，页面会自动更新；如果两边同时修改，会显示冲突选择对话框。

## 富内容

| 对象 | 可用交互 |
| --- | --- |
| 图片 | 粘贴保存到 `assets/`、拖拽调整、点击大图、滚轮缩放 |
| 表格 | 右键增删行列、整表对齐、拖动列宽 |
| 代码块 | 一键复制、语言选择、自动换行 |
| 公式 | 双击编辑、实时预览、可选编号 |
